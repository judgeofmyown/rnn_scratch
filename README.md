# RNN from Scratch 

## Overview
Implemented a **Recurrent Neural Network (RNN) from scratch** using **Python** and **NumPy**, focusing on sequence modeling fundamentals and neural network optimization techniques.

##  Key Features
- Built a **fully connected RNN** without relying on high-level ML frameworks.
- Implemented **Backpropagation Through Time (BPTT)** for training.
- Explored **gradient issues** like vanishing/exploding gradients.
- Applied **softmax activation** for sequential text prediction.
